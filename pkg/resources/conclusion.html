The driver is installed

Printer already set up? It now uses this driver. Try printing a label.

New printer? Plug it in and turn it on, then open System Settings → Printers & Scanners → Add Printer. Choose your printer. If the "Use" menu doesn't already show its open-source driver (for example "Polono PL60 (open-source driver)"), choose Select Software and pick it from the list.

To remove the driver later, run the "Uninstall Polono Driver" package from the same download page.
