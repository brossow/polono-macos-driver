# Developing

Needs the Xcode Command Line Tools (`xcode-select --install`). Nothing else.

```bash
make            # universal filter (arm64 + x86_64), ad-hoc signed, in build/
make test       # compare it with tests/cases, byte for byte, for every model
make ppds       # rewrite the PL70e-BT and PL420 PPDs from ppd/make_beeprt_ppds.py
make pkg        # test, then build/Polono-Driver-<version>.pkg and the uninstaller
```

The version is set at the top of the `Makefile`.

## Layout

| Path | What it is |
|---|---|
| `src/rastertotspl.c` | The CUPS filter, one profile per printer, picked by the PPD's `*PolonoProfile` |
| `ppd/PL60-open-source.ppd` | PL60 printer description: label sizes, options, USB device ID, filter name. Written by hand |
| `ppd/PL70e-open-source.ppd`, `ppd/PL420-open-source.ppd` | The PL70e-BT and PL420 descriptions, generated by `ppd/make_beeprt_ppds.py` (edit the script, then `make ppds`) |
| `pkg/scripts/postinstall` | Switches printers using Polono's PL60, PL70e-BT or PL420 driver to this one, keeping their settings, and refreshes printers already on it |
| `pkg/uninstall-scripts/postinstall` | Restores each switched printer's old PPD, then removes the driver |
| `pkg/build.sh`, `pkg/*.xml`, `pkg/*resources/` | Installer build and the installer's screens |
| `tests/<model>.cases` | The test-case table for each model |
| `tests/make-cases.sh`, `tests/run.sh` | Generate and check the test cases |
| `tests/decode_tspl.py` | Turns a TSPL job into a readable listing (`--ascii 80` sketches the bitmap) |
| `tests/make_test_pdf.py` | The test label: border, corner triangle, grey ramp, size text |

## Test cases

Each `tests/cases/<model>/<case>/` has the test PDF, the CUPS raster macOS made
from it (`input.ras.gz`, the filter's real input), the arguments (`args`), and the
expected output (`expected.tspl`, decoded in `expected.txt`). `tests/run.sh` checks
each model's cases with that model's PPD, `ppd/<model>-open-source.ppd`.

`make test-vectors` regenerates them from the current build (`MODELS="PL420"` for
just one). Only do that after a deliberate change to the output, checked against
Polono's driver or a real printer, because the cases are what tie every later
build to the output that was proven against Polono's driver (see
[TSPL.md](TSPL.md)).

### Adding a model

1. Work out exactly what Polono's driver sends for every option, and leave out
   anything that can't be reproduced exactly ([TSPL.md](TSPL.md) shows how).
2. Add a profile to `src/rastertotspl.c` and a PPD with a `*PolonoProfile` line,
   `*Product` lines for the model (and for Polono's own PPD, so the installer can
   recognise it) and a `*1284DeviceID`.
3. Add `tests/<model>.cases`, run `tests/make-cases.sh build/rastertotspl <model>`,
   and check every new `expected.tspl` against Polono's filter.
4. Teach `pkg/scripts/postinstall` (`identify`) and the uninstaller about it.

## Trying it by hand, without printing

```bash
cupsfilter -p ppd/PL60-open-source.ppd -m application/vnd.cups-raster -o PageSize=40x30mm label.pdf > label.ras
PPD=$PWD/ppd/PL60-open-source.ppd build/rastertotspl 1 me test 1 "PageSize=40x30mm" label.ras > label.tspl
python3 tests/decode_tspl.py label.tspl --ascii 80
```

## Notes

- `cupstestppd` passes with `-W sizes` for all three PPDs. Without it, it flags
  the size names (`w100h150` and so on). For the PL60 that's because by convention
  `wNhN` means points, not millimetres. For all of them it's because they aren't
  Adobe's standard names. Polono's PPDs use the same names, and they're kept so
  saved settings carry over.
- The PL70e-BT and PL420 `*1284DeviceID` lines are guesses, because no one has
  reported what those printers say over USB. Until then, macOS may not pick the
  driver by itself.
- The packages are unsigned. Signing and notarizing would need a paid Apple
  Developer ID. Files placed by the macOS Installer aren't quarantined, so CUPS
  runs the filter without a prompt. Only the downloaded `.pkg` needs Open Anyway.
- CUPS only runs filters owned by root and not writable by group or others. The
  package installs everything as `root:wheel` (`--ownership recommended`).
